# Adobe host compatibility

DepthVibe uses host-resident panels plus an authenticated local bridge. The panel runs inside Adobe; Flutter never attempts to load Adobe proprietary native binaries.

## Compatibility matrix

| Host | Integration | Status |
|---|---|---|
| Premiere Pro 25.6+ | UXP panel | Initial adapter source included |
| After Effects stable | CEP panel | Legacy compatibility source included |
| After Effects Beta 27.1+ | UXP | Public-beta panel source scaffold |
| Adobe native effects | .aex / .prm / C++ SDK | Not loaded by DepthVibe |

Adobe announced After Effects UXP public beta with After Effects Beta 27.1 build 27.1.0.045 and UXP 9.4. Adobe's CEP migration guidance says CEP will be disabled by default for After Effects in December 2028 and removed in December 2029. CEP is a legacy compatibility path.

## Local bridge transport and macOS TLS

The default bridge uses HTTP on the IPv4 loopback interface for desktop development. Adobe's UXP network guidance states macOS restricts insecure HTTP requests. For Premiere/After Effects UXP on macOS:

1. Create a local server certificate with 127.0.0.1 in its Subject Alternative Name (SAN):
   ```sh
   openssl req -x509 -newkey rsa:3072 -sha256 -days 365 -nodes \
     -keyout depthvibe-local.key \
     -out depthvibe-local.crt \
     -subj "/CN=DepthVibe Local Bridge" \
     -addext "subjectAltName=IP:127.0.0.1,DNS:localhost" \
     -addext "basicConstraints=critical,CA:TRUE" \
     -addext "keyUsage=critical,digitalSignature,keyEncipherment,keyCertSign" \
     -addext "extendedKeyUsage=serverAuth"
   ```
2. Add depthvibe-local.crt to the operating system trust store. On macOS, use Keychain Access or:
   ```sh
   security add-trusted-cert -d -r trustRoot \
     -k ~/Library/Keychains/login.keychain-db depthvibe-local.crt
   ```
   On Windows, run `certutil -user -addstore Root depthvibe-local.crt`. On Linux, install the certificate into the system trust store for the distribution.
3. In DepthVibe > Extension Manager > Adobe Integration, choose **Configure HTTPS for Adobe UXP** and select the .crt certificate and .key private key.
4. Set the Bridge URL in the Adobe panel to `https://127.0.0.1:47653` and pair again.

Protect the private key. Certificate/key files are loaded into the running DepthVibe process; select them again after restarting the app. On macOS, the UXP panel must use HTTPS. CEP may use HTTP where its embedded browser permits it.

## Premiere UXP

1. Install Premiere Pro 25.6+ and UXP Developer Tool.
2. Enable Developer Mode in Premiere's Plugins preferences.
3. In UXP Developer Tool choose Add Plugin and select integrations/adobe/premiere-uxp.
4. Load the panel from Window > UXP Plugins > DepthVibe Bridge.
5. Run DepthVibe, open the Compositor, then Extension Manager > Adobe Integration.
6. Enter the one-time pairing code shown by DepthVibe.

For production, package the panel to CCX with UXP Developer Tool. Install with Creative Cloud Desktop / UPIA and accept Adobe's permissions.

## After Effects CEP

The CEP source is in integrations/adobe/after-effects-cep. It is a compatibility path for stable releases where CEP remains enabled. Unsigned local development requires CEP debug mode; production distribution needs a publisher-signed ZXP and must follow Adobe's policies.

## After Effects UXP Beta

Install After Effects Beta and UXP Developer Tool v2.4+. Create an After Effects plugin from the built-in quick starter. Keep the host manifest generated by Adobe's tool, then copy this repository's index.html and index.js from after-effects-uxp-beta into the scaffold and add the local network permission plus `requiredPermissions.localFileSystem: "request"` for the export-script save dialog. This avoids guessing beta manifest schema.

## Bridge capabilities and limits

The first bridge supports one-time localhost pairing, effect descriptor listing, reading the open DepthVibe Compositor document as DepthVibe JSON and sending a DepthVibe-compatible JSON document back after an explicit user action.

The current adapters capture active Premiere sequences and After Effects compositions as editable DepthVibe layers. After Effects UXP exposes the installed-effect inventory and can synchronize native effect values and supported keyframes back to selected layers matched by persistent source ID. Native effect parameters retain matchNames and property paths, allowing nested parameter mapping. The .ffx import action uses the selected Layer's applyPreset() API. Import preserves Premiere track indices, clip timing and source references; After Effects import preserves layer timing, parent links, transform values and a bounded scalar-keyframe subset. The supported effect map and export limitations below are explicit; this is not a lossless converter for arbitrary Adobe projects.

Premiere .prm and After Effects .aex plugins are native binaries built against Adobe C++ SDKs and platform ABIs. They cannot run inside Flutter/Dart or be loaded from .dvext. Native Adobe effect support requires a separate plugin built and signed for its host and operating system. DepthVibe does not bundle Adobe SDKs or claim compatibility with arbitrary native Adobe plugins.


## Editable interchange workflow

1. Pair the Premiere Pro UXP / After Effects UXP Beta / After Effects CEP panel with DepthVibe.
2. Capture the active sequence or composition.
3. Choose **Import captured timeline into DepthVibe**. The bridge turns clip/layer timing, source in-points, visibility, parent links, transforms and the audited effect subset into editable DepthVibe layers.
4. Save as `.dvproj`. Adobe source identifiers and unsupported source effect records remain in each layer's interchange metadata.
5. Export from DepthVibe as Final Cut Pro 7 XML for Premiere Pro (File > Import), or save the generated After Effects ExtendScript and run it using File > Scripts > Run Script File.

### Verified scope and limitations

Media bytes are not copied. Only genuine local footage paths are linked; missing media remains offline and must be relinked. Premiere FCP XML exports clip placement/media references and the verified static Gaussian Blur filter (channel/radius). Other effects and animated Gaussian Blur curves remain unsupported in this interchange path until their XMEML parameter/curve mapping is verified. The After Effects script creates editable layers and applies only the explicit built-in subset: Brightness, Contrast, Gaussian Blur, Sharpen, Invert and Hue/Saturation. Expressions, arbitrary keyframe graphs, third-party effects, nested sequences/comps, complete audio routing and every blend-mode variant are not losslessly converted. Unsupported effect metadata is preserved and reported, not executed.


The Premiere UXP manifest requests the UXP local file-system save permission. The After Effects UXP Beta adapter is source for Adobe's generated starter project; retain its generated host manifest and add both the loopback network permission and local file-system request permission there.


### Track and animation interchange (current increment)

- Premiere XML groups clips by the original Premiere video/audio track index instead of creating one export track per clip. Clips on a track remain sorted by sequence start time.
- After Effects UXP and CEP capture scalar transform keyframes for Position, Anchor Point, Scale, Rotation and Opacity. Two- and three-dimensional values are split into scalar DepthVibe tracks.
- Supported effect parameter keyframes are imported for Gaussian Blur, Brightness, Contrast, Sharpen and Saturation.
- The After Effects JSX exporter recreates supported scalar/vector keys and their HOLD / LINEAR / Bezier interpolation category. Spatial tangents, temporal ease curves, roving and separated-dimension controls are not yet lossless.
- Expressions are recorded as inert source metadata; they are never executed by DepthVibe or automatically re-enabled by the generated import script.


### Spatial/temporal keyframe and effect-filter increment

- After Effects UXP Beta 27.0+ and CEP snapshots now attempt to capture per-key incoming/outgoing interpolation, temporal ease speed/influence arrays, spatial in/out tangents, roving, spatial/temporal auto-Bezier and continuity flags. Each keyframe carries the raw supported values into the DVPROJ project data.
- The generated After Effects script restores separate in/out interpolation, temporal ease, spatial tangents, auto-Bezier/continuity flags and roving where the destination property supports the relevant API. Host API failures are reported as warnings rather than silently converted.
- Premiere FCP7 XML now writes the documented static Gaussian Blur filter schema (channel and radius). Effects without a verified portable XMEML effect ID/parameter contract, and animated Gaussian Blur curves, remain listed as unsupported rather than being emitted using guessed identifiers.
- Real host validation is still required in supported After Effects and Premiere versions. This richer interchange is not a guarantee of lossless conversion for all projects or third-party plugins.


### Expanded native effects, transitions and motion presets

The Effects panel now includes additional native renderable effects: Exposure, Hue Rotate, Colorize, Directional Blur, Average Blur, Chroma Denoise, Deband, Deflicker, Scanlines, RGB Split, Posterize Time, Echo Trails, VHS Warp, Fisheye, Radial Blur and Spatial Noise Reduction. These use FFmpeg filters and are not Adobe binary plug-ins.

The transition picker includes the FFmpeg xfade transition family, including slides, circles, rectangles, radial/diagonal wipes, slices, wind, squeeze, cover and reveal variants. Each kind maps to its FFmpeg xfade identifier. Some live preview transitions remain approximations; final export uses xfade.

The Effects panel also includes 20 original editable motion recipes. Applying a recipe writes ordinary keyframe tracks at the playhead, so users can edit them in the timeline/graph editor afterwards.

Premiere UXP capture queries the host's installed video transition match-name list and active transition track-items where supported. Imported Premiere transition match-names and source descriptors persist in DVPROJ projects. The After Effects JSX importer attempts exact native match-names from unmatched source effect descriptors when the same effect is installed in the target application; missing plug-ins are reported rather than replaced with invented effects.

These additions are native DepthVibe equivalents and host interoperability paths, not a redistribution of licensed Motion Bro packs or a claim that every third-party Adobe effect can run without its original plug-in.


### Transition export to both Adobe hosts

The Premiere XML writer now places XMEML transitionitem nodes between the relevant clip items on their shared track. It uses the original Premiere transition match-name when one was captured; otherwise it uses the DepthVibe transition identifier and display name. Apple documents transitionitem/effect as the interchange structure, but a syntactically valid XML file does not guarantee every host will bind every proprietary transition identically. Adobe will need to resolve the identifier or show a generic transition proxy on projects whose effects do not exist on the target machine.

The After Effects script recreates imported Premiere transitions as editable opacity keyframes, with positional/scale motion for common slide and zoom transitions. It does not execute the proprietary Premiere transition plug-in or claim parameter-exact parity.


### Native Adobe effect catalogs and plugin round-trip

The After Effects Beta UXP panel uses the AE 27.0+ `app.effects` inventory and shows a searchable list of installed effects. Applying an item adds the actual match-name effect to the currently selected AE layers; DepthVibe then captures its property tree, parameter values, supported scalar keyframes, units/ranges and inert expression text. A target AE installation must contain the same third-party plug-in for native re-creation.

After Effects 27.0+ also exposes `.ffx` animation preset apply/save APIs. The UXP panel can apply an existing `.ffx` file to selected layers and capture the resulting composition in DepthVibe, or save selected AE properties as a native `.ffx` file. The separate `.dvmpreset` package carries DepthVibe effects, keyframes and native match-name/property descriptors, but not plug-in binaries or external media.

Premiere Pro 25.6+ UXP exposes VideoFilterFactory inventory by match-name/display-name and AudioFilterFactory inventory by display-name. The panel searches both catalogs, applies a native effect to the selected captured video/audio clip, reads parameter values and keyframe times, and synchronizes supported settings from DepthVibe back through Premiere project transactions. Audio-filter identifiers are display-name based; video-filter identifiers are match-name based.

Parameter values are editable in the DepthVibe native-effect panel when a safe scalar range is exposed. Opaque/vector/plugin-specific values remain preserved as native metadata and are applied by the relevant Adobe host when its API supports that value type. For Premiere, keyframe values/interpolation are captured, and the adapter uses ComponentParam time-varying/add-keyframe actions when supported. Parameters without a supported host keyframe API are reported as skipped instead of silently approximated.

This is native-host execution, not a claim that proprietary Adobe plug-ins can run inside DepthVibe's FFmpeg renderer. Unsupported effects stay tagged as native host effects until a portable DepthVibe renderer exists.


### Motion Bro .MBR pack support

The Compositor can import user-supplied legacy `.MBR` packages. The importer reads root `pack.info` metadata (including inline comments used in Motion Bro examples), category/subcategory folders, optional `(Assets)` files and `(Preview)` folders. It keeps original preset/media files, identifies `.FFX` and `.MOGRT` separately, and matches same-basename previews even when their extension differs from the preset.

The After Effects UXP panel can apply imported `.FFX` files to selected layers; the Premiere UXP panel can insert imported `.MOGRT` files at the active sequence playhead. The imported library is not a license activator: current Motion Bro packs that require a license key still require their original valid license and supported Motion Bro workflow. DepthVibe does not unlock, decrypt, remove activation checks or alter licensed pack contents. The importer does not execute `.JSX` or `.JSXBIN` code.


### Native AE effect keyframe fidelity

When the After Effects UXP host reports keyframe metadata for a native effect parameter, the Sync action now attempts to restore incoming/outgoing HOLD / LINEAR / BEZIER interpolation, temporal ease speed/influence, temporal/spatial auto-Bezier and continuity, spatial in/out tangents and roving flags. Each optional host operation is feature-detected; unsupported property types or host API methods are reported/skipped and are not claimed as losslessly mapped.
